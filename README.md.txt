

## Project Description
This is a simple text-based Hangman game developed using Python.

The player has to guess a randomly selected word by entering one letter at a time.

## Features
- Contains 5 predefined words.
- Maximum 6 incorrect guesses.
- Displays correctly guessed letters.
- Prevents repeated guesses.
- Validates user input.
- Provides an option to play again.

## Technologies Used
- Python
- Random module
- Basic functions and loops

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Run the following command:

bash
python hangman.py
